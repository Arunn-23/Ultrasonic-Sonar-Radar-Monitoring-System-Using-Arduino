# 🔌 Hardware & Wiring

## Components

- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- Servo Motor
- 16×2 LCD Display
- LED
- Resistors
- Breadboard
- Jumper Wires
- Power Supply

## Pin Connections

### HC-SR04 Ultrasonic Sensor

| HC-SR04 Pin | Arduino UNO |
|---|---|
| VCC | 5V |
| GND | GND |
| TRIG | D2 |
| ECHO | D3 |

### Servo Motor

| Servo Pin | Arduino UNO |
|---|---|
| Signal | D9 |
| VCC | 5V |
| GND | GND |

### LED

| LED Pin | Arduino UNO |
|---|---|
| Anode (+) | D13 through resistor |
| Cathode (-) | GND |

### 16×2 LCD

| LCD Pin | Arduino UNO |
|---|---|
| RS | D7 |
| EN | D8 |
| D4 | D4 |
| D5 | D5 |
| D6 | D6 |
| D7 | D10 |
| VSS | GND |
| VDD | 5V |
| V0 | Contrast control |
| A/K | Backlight |

> **Important:** Verify the wiring with the actual hardware before powering the circuit. The project report contains a general circuit diagram and connection description rather than a fully consistent pin-by-pin wiring table. 0
