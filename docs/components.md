# 🧩 Components Used

## 1. Arduino UNO

Arduino UNO acts as the main control unit of the system. It receives the ultrasonic sensor data, processes the measured distance, controls the servo motor, and manages the output indicators.

## 2. HC-SR04 Ultrasonic Sensor

The HC-SR04 is used for non-contact distance measurement. It transmits ultrasonic waves and receives the reflected echo from an object.

The Arduino uses the echo time to calculate the approximate distance.

## 3. Servo Motor

The servo motor rotates the ultrasonic sensor through different angles, allowing the system to scan different directions.

## 4. 16×2 LCD Display

The LCD provides a visual interface for displaying the measured distance and system status.

## 5. LED

The LED provides a visual indication when an object is detected within the programmed detection range.

## 6. Resistors

Resistors are used for appropriate current limiting and circuit protection.

## 7. Breadboard

The breadboard provides a temporary platform for connecting and testing the electronic components during prototyping.

## 8. Jumper Wires

Jumper wires are used to establish electrical connections between the Arduino, sensor, servo, LCD and other components.

## 9. Power Supply

The power supply provides the required electrical power to operate the system.

## 10. Voltage Regulator

A voltage regulator is used to provide a stable supply voltage to the circuit.
